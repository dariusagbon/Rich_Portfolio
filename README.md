# Rich_Portfolio

Portfolio site for **Jian Rich C. Dumapias**, a Virtual Administrative Assistant offering real estate and property management support. It is a static, single-page site with an editorial black and cream layout.

## Run it

Open `index.html` in a browser. There is no build step.

## Customize

- **Photos:** see [`images/README.md`](images/README.md) for the filenames.
- **Content:** all text (profile, skills, experience, education, contact) is in `index.html`.
- **Colors and fonts:** these are CSS variables at the top of `css/style.css`.
