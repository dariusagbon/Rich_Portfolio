# Images

The site loads photos from this folder by filename. To swap a photo, replace the file but keep its name. If a file is missing, that spot shows a soft neutral placeholder.

All five current files are crops of two photos. The header photo is shown whole and centred over a blurred copy of itself, so a portrait-shaped photo works there.

| File | Where it appears | Suggested size / shape |
|------|------------------|------------------------|
| `hero.jpg` | Full-width header photo behind your name | portrait or landscape, at least 800px tall |
| `intro-1.jpg` | Large photo, left of the intro text | 900×1030, portrait |
| `intro-2.jpg` | Small overlapping photo (moodier / darker works best) | 400×530, portrait |
| `intro-3.jpg` | Small photo pinned to the right edge | 400×600, portrait |
| `portrait.jpg` | Arch-shaped portrait above the About section | 600×740, portrait, plain background |
