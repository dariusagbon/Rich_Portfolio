# Images

Drop your photos here using these exact filenames. Until a file exists, the site shows a soft neutral placeholder in its spot.

| File | Where it appears | Suggested size / shape |
|------|------------------|------------------------|
| `hero.jpg` | Full-width header photo behind your name | 2000×1000, landscape, face in the upper-centre |
| `intro-1.jpg` | Large photo, left of the intro text | 900×1030, portrait |
| `intro-2.jpg` | Small overlapping photo (moodier / darker works best) | 400×530, portrait |
| `intro-3.jpg` | Small photo pinned to the right edge | 400×600, portrait |
| `portrait.jpg` | Arch-shaped portrait above the About section | 600×740, portrait, plain background |
